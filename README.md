# Flashback Inventory Addon (Fabric 1.21.11)

Клиентский аддон для [Flashback](https://modrinth.com/mod/flashback) (проверено по версии 0.39.10 для 1.21.11).

Flashback сам записывает только хотбар игрока. Этот аддон дополнительно записывает **открытое меню**
(инвентарь, сундуки, бочки, шалкеры, эндер-сундук, воронки, раздатчики и любые другие меню) и показывает его
в реплее, когда ты смотришь **от лица этого игрока** (Spectate player -> first person):
видно, какие предметы лежат в слотах, что игрок берёт и что тащит курсором.

## Как это работает
- **Запись:** каждый тик аддон смотрит, открыто ли меню у записывающего игрока. При изменении (и раз в секунду как
  «пульс») он пишет в реплей пакет `flashbackinv:container_view` с содержимым всех слотов, предметом в курсоре и
  положением курсора. Для записи используется публичный метод `Recorder.writePacketAsync` из Flashback.
- **Просмотр:** пакет приходит из реплея, аддон запоминает его и рисует окно меню поверх экрана.
  Окно скрывается, когда игрок закрыл меню, или если данных нет дольше 3 секунд (например, после перемотки).

Аддон не использует mixin'ы, поэтому не ломается от внутренних изменений Flashback.
Flashback подключается через рефлексию, и для сборки его jar не нужен.

## Сборка
Нужны Java 21 и Gradle (Gradle Wrapper в репозиторий не входит).

    gradle build

Готовый файл: `build/libs/flashback-inv-<версия>.jar` (не `-sources`). Положи его в `mods` рядом с Flashback и Fabric API.
Либо запусти workflow в GitHub Actions (вкладка Actions -> Build Fabric Mod -> Run workflow) и скачай jar из Artifacts.

Если Gradle ругается на версии плагина/Loom, открой https://fabricmc.net/develop, выбери 1.21.11, поправь
значения в `gradle.properties` (`loader_version`, `loom_version`, `fabric_api_version`).

## Ограничения
- Работает только для записей, сделанных **с этим аддоном**. Старые реплеи меню не содержат.
- Показывается меню только записывающего игрока (Flashback пишет первое лицо только одного игрока).
- Подсказок (tooltip) при наведении на предметы нет.
- Анимации перетаскивания «пачкой» (drag-split) показываются как последовательность состояний слотов.
